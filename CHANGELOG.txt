I. TỔNG HỢP THAY ĐỔI THEO TỪNG CLASS / PACKAGE

1. Package util
--------------------------------------------------------------------------------
- InputValidator.java:
  + Sửa lỗi nhập ngày (kể cả 2026-06-12): Đưa định dạng "yyyy-MM-dd" lên ưu tiên
    số 1 trong danh sách DATE_FORMATTERS, hỗ trợ thêm "dd/MM/yyyy", "d/M/yyyy",
    "dd-MM-yyyy", "yyyy/MM/dd".
  + Bắt triệt để cả DateTimeParseException và Exception trong readValidDate(),
    ngăn chặn hoàn toàn lỗi ngoại lệ chưa xử lý làm dừng chương trình.
  + Thêm hàm readConfirmation(String prompt) hỗ trợ đọc lựa chọn xác nhận (Y/N).
  + Đã xóa toàn bộ comment và Javadoc thừa.

3. Package file
--------------------------------------------------------------------------------
- AbstractFileIO.java:
  + Đổi cơ chế đọc/ghi sang StandardCharsets.UTF_8 qua InputStreamReader /
    OutputStreamWriter (không phụ thuộc vào bảng mã mặc định của Windows).
  + Bổ sung bộ lọc tự động nhận diện và cắt bỏ ký tự UTF-8 BOM (\uFEFF) ở dòng đầu
    tiên của file để tránh lỗi bị lệch độ dài chuỗi và lỗi tra cứu mã vạch.
  + Bổ sung hàm getFile() linh hoạt tìm đúng vị trí file text khi chạy trên
    NetBeans hoặc chạy qua Terminal.
  + Đã xóa toàn bộ comment và Javadoc thừa.

- ProductFile.java:
  + Cải tiến hàm dataToObject() hỗ trợ xử lý tên sản phẩm chứa dấu phẩy
    (ví dụ: "Instant coffee, 3 in 1"), đảm bảo trích xuất chính xác mã vạch, giá,
    đơn vị tính và phân loại.
  + Đã xóa toàn bộ comment và Javadoc thừa.

- WarehouseFileService.java:
  + Bổ sung cờ theo dõi trạng thái thay đổi dữ liệu: modified, isModified(),
    markModified(), setModified(boolean).
  + Trong hàm loadAll(): Tự động làm sạch dữ liệu cũ trong RAM trước khi nạp
    (gọi clear() trên ProductManager và TransactionLog) để tránh bị duplicate
    sản phẩm hoặc lô hàng. Tự động reset modified = false.
  + Trong hàm saveAll(): Ghi dữ liệu đồng bộ ra 3 file: products.txt, batches.txt,
    transactions.txt. Lưu thành công tự động reset modified = false.
  + Đã xóa toàn bộ comment và Javadoc thừa.

- BatchFile.java, TransactionFile.java, IFileIO.java:
  + Đã xóa toàn bộ comment và Javadoc thừa.
